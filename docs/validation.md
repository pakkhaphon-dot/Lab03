# Lab 03 · Browser Acceptance Results

ค่าร่วมทุกกรณี: VCC = 12 V, RC = 2.2 kΩ, β = 100, VBE = 0.70 V

วิธีตรวจทุกกรณี: **Playwright MCP** (`browser_navigate` → `browser_fill_form` →
`browser_click` → `browser_snapshot`) กับ URL `http://127.0.0.1:5000/`

## ค่าอ้างอิงอิสระ (คำนวณจากสมการก่อนรัน ไม่ได้เอาค่าจากโปรแกรม)

กรณีที่เลือก: **A2 · Fixed Bias** (RB = 1 MΩ)

สมการที่ใช้ (หน่วย Ω และ A):
```
I_B = (V_CC − V_BE) / R_B = (12 − 0.70) / 1,000,000 = 11.3 µA
I_C = β I_B = 100 × 11.3 µA = 1.130 mA
V_E = 0 V (Fixed bias, emitter ต่อกราวด์โดยตรง)
V_C = V_CC − I_C R_C = 12 − (1.130 mA × 2.2 kΩ) = 9.514 V
V_CE = V_C − V_E = 9.514 − 0 = 9.514 V
```

ค่าคาดหมาย (ยังไม่ปัดเศษ): **I_C = 1.130000 mA · V_CE = 9.514000 V**

สมการที่ใช้คำนวณค่าคาดหมายกรณีอื่น (จาก Engineering Electronics):

| กรณี | สมการหลัก | I_C (ไม่ปัด) | V_CE (ไม่ปัด) |
|---|---|---|---|
| A1 Divider | V_TH = 12·22/(100+22) = 2.163934 V, R_TH = 100·22/122 = 18.032787 kΩ, I_B = (V_TH−0.70)/(R_TH+101·1k) = 12.2986 µA | 1.229858 mA | 8.052155 V |
| A3 Emitter | I_B = 11.3/(1 MΩ + 101·1 kΩ) = 10.2634 µA | 1.026340 mA | 8.705450 V |
| A4 Emitter | I_B = 11.3/(1 MΩ + 101·2 kΩ) = 9.4010 µA | 0.940100 mA | 8.032779 V |

- |ΔV_CE| ≤ 0.02 V

## ทวนผลเองอย่างน้อย 1 กรณี

กรณีที่ทวน: **A4** (เปลี่ยน R_E จาก 1 เป็น 2 kΩ แล้ว IC ลดจาก 1.026 → 0.940 mA)

เส้นทางข้อมูล R_E ใน A4 (ฟอร์ม → Flask → แปลงหน่วย → ฟังก์ชัน → ผล):

```
1. ฟอร์ม: <input id="re" name="re" type="number" value="2">  (หน่วย kΩ)
2. Flask (app.py): request.form.get("re") → "2"
3. _parse_positive() → 2.0 (ตรวจว่าเป็นตัวเลข จำนวนจำกัด และ > 0)
4. SCALE_TO_OHMS["re"] = 1000 → values["re"] = 2000.0 Ω  (แปลงครั้งเดียวที่จุดรับข้อมูล)
5. MODE_FIELDS["emitter"] = ("rb", "re") → ส่ง 2000.0 เป็น argument ที่ 6
6. CALCULATORS["emitter"] → dc_bias.emitter_bias(vcc, rc, beta, vbe, rb, re)
7. dc_bias.py: ib = (vcc - vbe) / (rb + (beta + 1) * re)
                 = 11.3 / (1,000,000 + 101 × 2,000) = 9.4010 µA
8. _finish(): ic_ma = (beta * ib) * 1e3 = 0.940100 mA
9. templates/index.html: {{ "%.3f"|format(result.ic_ma) }} mA → "0.940 mA"
```

ผลการทวน: ค่าที่เห็นตรงกับค่าคาดหมายอิสระ (0.940100 mA → 0.940 mA,
8.032779 V → 8.033 V) ภายใต้ tolerance ที่กำหนด

## คำถามปิด Lab

**ถ้าตัวเลขคำนวณมือถูก แต่เปลี่ยน R_E แล้วผลบนหน้าเว็บไม่เปลี่ยน จะตรวจอย่างไร?**

ไล่ทีละจุดตามเส้นทางข้อมูล:

1. **ค่าที่ส่งจากฟอร์ม** — อ่าน `browser_snapshot` หลังเปลี่ยน R_E ว่าช่องมีค่าใหม่จริง
   หรือไม่ ถ้า UI ใช้ JS toggle ให้ตรวจว่าช่องนั้นไม่ได้ `disabled` (input ที่ disabled
   จะไม่ถูกส่ง) และปุ่มถูกกดจริง
2. **ชื่อฟิลด์ที่ Flask รับ** — ตรวจว่า `name` ของ input ตรงกับ `_parse_positive(request.form, ...)`
   และอยู่ใน `MODE_FIELDS[mode]` (เช่น `"re"`); ถ้าชื่อไม่ตรง Flask จะได้ค่าเริ่มต้นหรือ error
3. **การแปลงหน่วย** — ตรวจ `SCALE_TO_OHMS["re"] = 1000` ว่าค่า kΩ ถูกคูณเป็น Ω
   (2 → 2000 Ω) ไม่ใช่ปล่อยเป็น 2 Ω
4. **ฟังก์ชันที่ถูกเรียก** — ตรวจ `CALCULATORS[mode]` ว่าเป็น `emitter_bias` ไม่ใช่
   `fixed_bias` หรือ `voltage_divider_bias` และ `re` ถูกส่งเป็น argument ที่ถูกตำแหน่ง
5. **ค่าที่แสดง** — ตรวจว่ากำลังอ่าน snapshot หลังส่งฟอร์มรอบนี้ ไม่ใช่ผลรอบก่อน
   และรูปแบบ `%.3f` ไม่ได้ปัดจนค่าต่างหายไป

หากทุกจุดถูกต้องแต่ผลยังเท่าเดิม ให้ดู `git diff` ของไฟล์ที่เปลี่ยนแล้วรันกรณีที่
ได้รับผลกระทบซ้ำ อย่าแก้สมการก่อนยืนยันเส้นทางข้อมูล
